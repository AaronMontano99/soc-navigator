## Not tested here

These rules read identity-provider, email-gateway, SaaS or aggregated file telemetry, which these Windows host recordings don't contain: `anomalous_login_location`, `credential_stuffing_bruteforce`, `exfiltration_to_personal_cloud`, `mass_file_download_anomaly`, `mass_file_modification_ransomware`, `phishing_link_click`, `privileged_action_new_session`.

## Limits

- The datasets have recording-level labels, not per-event ones, so precision isn't claimed. Unexpected alerts are listed with their evidence for a person to judge.
- Recordings are from 2019-2020 lab hosts. They show whether a rule's logic survives real logs, not how it would do on today's tooling or in a busy network.
